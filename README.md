# Health Care Medical Services 🏥

تطبيق ويب ذكي لطلب خدمات تمريض وخدمات طبية منزلية.

## المميزات الرئيسية ✨

- 🩺 طلب خدمات تمريض فورية
- 👨‍⚕️ اختيار الممرضات والممرضين القريبين
- 📍 تتبع موقع مقدم الخدمة
- ⭐ تقييم المقدمين
- 💳 نظام دفع آمن
- 📞 التواصل المباشر

## التقنيات المستخدمة 🛠️

- **Frontend:** React + Tailwind CSS
- **Routing:** React Router
- **State Management:** Context API
- **API Client:** Axios
- **Build Tool:** Vite/Create React App

## البدء السريع 🚀

### المتطلبات
- Node.js (v14+)
- npm أو yarn

### التثبيت

```bash
# Clone the repository
git clone https://github.com/abdoatea13/health-care-medical-servises.git
cd health-care-medical-servises

# Install dependencies
npm install

# Start development server
npm run dev
```

## هيكل المشروع 📁

```
src/
├── components/          # React Components
├── pages/              # صفحات التطبيق

├── services/           # API Services
├── assets/             # الصور والأيقونات

```
